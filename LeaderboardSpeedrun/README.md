# Leaderboard Speedrun -- GDScript
A multiplayer demo built with Godot 4.5 (GDScript) that demonstrates brainCloud's leaderboard services. 

This project is the final project files of the game made in this video:
[Making a Game With a brainCloud Leaderboard [10:35] [PB]](https://youtu.be/7paOSb2wemc)

This project was made in Godot 4.6 (standard build — no .NET required)

## Setup -- Opening the project

After downloading the `examples-godot` repo, open Godot's project manager and click the 'Import' button in the top right. This will bring up a file browser. Select the `LeaderboardSpeedrun` folder. This will open the project with the Godot editor and add it to your project list for the future. 

## Setup -- Entering your app credentials

The brainCloud plugin adds a 'brainCloud' dock (usually grouped on the right with the 'Inspector' and 'Signals' tabs). Open it and log in with your brainCloud account to pick an app, or create an new app directly, then click Save.

The plugin window also includes quick links to the Portal, API Reference, documentation, and the GDScript SDK on GitHub.
